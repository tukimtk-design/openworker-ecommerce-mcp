ส่วนที่ 1: ภาพรวมโปรเจกต์และสถาปัตยกรรม (PROJECT OVERVIEW & ARCHITECTURE)
================================================================================
1.1 วัตถุประสงค์หลัก:
Openworker E-Commerce MCP Server พัฒนาขึ้นเพื่อแก้ปัญหาการทำงานอัตโนมัติของบอทบนร้านค้า E-Commerce (Shopee, TikTok Shop, Lazada, LnwShop) โดยมีหลักการทำงานสำคัญ:
- เชื่อมต่อผ่าน Session จริง (CDP Port 9222): เกาะ Chrome หรือ Edge ของผู้ใช้ที่ล็อกอิน Seller Center ค้างไว้ ไม่ต้องล็อกอินใหม่หรือเจอด่าน OTP/2FA ซ้ำซาก
- ดึง Session Cookies & Tokens เพื่อยิง Direct API: ดึง Headers/Cookies แล้วส่งคำสั่งอัปเดตผ่าน API ตรง รวดเร็วในระดับมิลลิวินาที ไม่พึ่งพา DOM Selector เพียงอย่างเดียว
- Human-in-the-Loop & Safety Guard: มีระบบตรวจจับความผิดปกติของราคา (สกัดกั้นการลดราคาฮวบเกิน 50%) และตรวจจับ Captcha/Challenge เพื่อหยุดรอให้มนุษย์ช่วยแก้
- ประหยัด Token สูงสุด: มีระบบ Context Compressor ย่อ HTML เหลือ Micro-JSON, บันทึก Token Telemetry, และระบบ Smart Diff Update ส่งเฉพาะจุดที่เปลี่ยน

1.2 แพลตฟอร์มที่รองรับ:
1. Shopee (Seller Centre TH)
2. TikTok Shop (Seller Center TH)
3. Lazada (Seller Center TH)
4. LnwShop / CapsuleFill (PHP Session & Web Portal)

1.3 การตั้งค่า Google Vertex AI สำหรับ Openworker (`secrets.json`):
ตำแหน่ง: `C:\Users\%USERNAME%\AppData\Roaming\coworker\secrets.json`
ตั้งค่า: `"providers": { "vertex": { "project": "your-project-id", "location": "global" } }`
(แนะนำให้ใช้ `location: "global"` เพื่อความเข้ากันได้ 100%)

ส่วนที่ 2: กฎเหล็ก ZERO-DEFECT PROTOCOL (VERTEX AI & CLAUDE COMPATIBILITY)
================================================================================
เพื่อป้องกัน Error `400 INVALID_ARGUMENT` บน Vertex AI และ Claude:
1. STRICT TYPING MANDATE:
   - ทุกฟิลด์ที่เป็น `"type": "array"` ต้องระบุ `"items"` กำกับชนิดข้อมูลเสมอ ห้ามสร้าง Array เปล่า
   - ทุกฟิลด์ที่เป็น `"type": "object"` ต้องมี `"properties"` และ `"required"` เสมอ หากเป็น Dynamic Object ต้องใส่ Dummy Property `_dummy` และ `additionalProperties: true`
   - ห้ามใช้ `$schema`, `$ref`, `patternProperties` หรือ nested `anyOf` ซับซ้อน
2. STRICT NAMESPACE:
   - เครื่องมือใหม่ทุกตัวต้องขึ้นต้นด้วย Prefix `ecommerce_*` เท่านั้น
3. PRE-BUILD VALIDATION:
   - ทุกโค้ดต้องผ่าน `npm run build` (TypeScript Typecheck) และ Unit Test 100% ก่อน Controller อนุมัติ

ส่วนที่ 3: สรุปรายการ MCP TOOLS ทั้งหมด 32 ตัว (TOOLS CATALOG)
================================================================================
หมวดที่ 1: Browser & Session
1. `browser_attach_existing` : เชื่อมต่อ Chrome/Edge บนพอร์ต 9222 และแสดงรายชื่อแท็บร้านค้า
2. `ecommerce_extract_session` : ดึง Cookies, CSRF Token, Auth Headers จาก Shopee/TikTok/Lazada/LnwShop

หมวดที่ 2: Core Product & Safety
3. `ecommerce_product_search` : ค้นหารายการสินค้าและ SKU ในระบบหลังบ้าน
4. `ecommerce_update_price_stock` : ปรับเปลี่ยนราคาและจำนวนสต็อกสินค้า
5. `ecommerce_safety_guard` : ตรวจสอบส่วนต่างของราคาก่อนบันทึกจริงเพื่อป้องกันราคาผิดพลาด

หมวดที่ 3: Safety, Metrics & Audit
6. `browser_detect_challenge` : สแกนหา Captcha/OTP และแจ้งเตือนให้มนุษย์ช่วยแก้
7. `ecommerce_get_store_metrics` : ดึงสถิติร้าน ออเดอร์ค้าง และสินค้าใกล้หมดสต็อก
8. `ecommerce_batch_update_price_stock` : อัปเดตราคา/สต็อกแบบ Batch พร้อม Anti-Rate-Limit Delay
9. `ecommerce_audit_log` : บันทึกและเรียกดูประวัติการเปลี่ยนแปลงราคาย้อนหลัง

หมวดที่ 4: Recipes & Workflows
10. `ecommerce_run_recipe` : รัน Macro Workflow Recipe ที่กำหนดไว้
11. `ecommerce_list_recipes` : แสดงรายการ Recipe ทั้งหมดในระบบ
12. `ecommerce_save_custom_recipe` : บันทึก Custom Workflow Recipe
13. `ecommerce_cached_selector_map` : จัดการแคช Selector หน้าเว็บ พร้อมระบบ Auto-Healing

หมวดที่ 5: Token Optimization & Cache
14. `ecommerce_context_compressor` : บีบอัด DOM HTML ให้เหลือ Micro-JSON ประหยัด Token > 70%
15. `ecommerce_local_sqlite_cache` : อ่าน/เขียนข้อมูลลง SQLite ในเครื่อง
16. `ecommerce_smart_diff_update` : คำนวณ Delta Diff เพื่ออัปเดตเฉพาะจุดที่เปลี่ยนแปลง
17. `ecommerce_hybrid_executor` : สลับการทำงานระหว่าง Direct API, CDP Browser, และ Human Intervention
18. `ecommerce_token_telemetry` : บันทึกและดึงสถิติการใช้/ประหยัด Token

หมวดที่ 6: Cross-Platform & Visual
19. `ecommerce_match_variants` : จับคู่ Variant ข้ามแพลตฟอร์มด้วย Fuzzy Matching
20. `ecommerce_sync_multiplatform_stock` : ซิงค์สต็อกและราคาข้ามหลายแพลตฟอร์มพร้อมกัน
21. `ecommerce_visual_dom_analysis` : จับภาพ Screenshot และ Bounding Box เพื่อแก้ Selector เพี้ยน

หมวดที่ 7: Autonomous Suite
22. `ecommerce_autonomous_store_manager` : Background Agent Loop ตรวจสต็อก แชท ราคา อัตโนมัติ 24/7
23. `ecommerce_clone_product` : โคลนสินค้าจาก URL ต้นฉบับ แปลภาษา และโพสต์ลงหลายแพลตฟอร์ม
24. `ecommerce_auto_reply_chat` : ดึงแชทที่ยังไม่ได้อ่านและตอบกลับอัตโนมัติ
25. `ecommerce_get_pending_orders` : ดึงรายการออเดอร์ที่ค้างจัดส่ง
26. `ecommerce_fulfill_order` : สั่งจัดเตรียมพัสดุและแจ้งเลขพัสดุ
27. `ecommerce_manage_promotions` : จัดการ Flash Sale และคูปองโปรโมชัน
28. `ecommerce_sync_product_images` : ซิงค์รูปภาพสินค้าข้ามแพลตฟอร์ม

หมวดที่ 8: Enterprise Integrations
29. `ecommerce_m365_copilot_bridge` : เชื่อมต่อและสนทนากับ Microsoft 365 Copilot ผ่าน CDP
30. `ecommerce_seo_optimizer` : ปรับปรุง On-page SEO และสร้าง JSON-LD Schema
31. `ecommerce_ow_lnwshop_safe_seo_updater` : อัปเดต SEO Meta บน LnwShop อย่างปลอดภัย
32. `ecommerce_google_ads_integration` : เชื่อมต่อ Google Ads Campaign และ Offline Conversion Tracking
