1. ปัญหาและที่มาของโครงการ (PROBLEM STATEMENT & SOLUTION)
--------------------------------------------------------------------------------
ปัญหาของบอท E-Commerce ทั่วไป:
1.1 โดนบล็อคจากระบบล็อกอิน / เจอด่าน 2FA/OTP ซ้ำซาก:
    บอททั่วไปพยายามเปิดเบราว์เซอร์ใหม่ (Clean Profile) ทำให้ต้องล็อกอินใหม่ทุกครั้งและติดด่านความปลอดภัย
1.2 ทำงานช้าและเปลือง Token:
    การสั่งคลิก UI ทีละจุดผ่าน DOM Selector กินเวลาและทำให้ LLM ต้องประมวลผล HTML ขนาดใหญ่
1.3 เสี่ยงต่อการตั้งราคาผิดพลาด (Fat-finger error):
    บอททั่วไปไม่มีระบบตรวจจับความผิดปกติของราคา หาก AI คำนวณราคาผิด อาจทำให้ร้านค้าขาดทุนมหาศาล

โซลูชันของ Openworker E-Commerce MCP:
1. Connect ผ่าน Session จริง (CDP Port 9222):
   - เชื่อมต่อเบราว์เซอร์ Chrome หรือ Edge ที่ผู้ใช้ล็อกอิน Seller Center ค้างไว้อยู่แล้วผ่าน Chrome DevTools Protocol (CDP)
   - ไม่ต้องส่ง Username/Password ในโค้ด และไม่ต้องล็อกอินใหม่
2. อัปเดตรวดเร็วด้วย Internal API Interception:
   - ดึง Auth Cookies, CSRF Tokens, และ Headers จากหน้าเว็บที่เปิดอยู่ แล้วส่งคำสั่งอัปเดตผ่าน API ภายในของแพลตฟอร์มโดยตรง
   - ทำงานได้ในระดับมิลลิวินาที แม่นยำ ไม่ต้องพึ่งพา DOM Selector เพียงอย่างเดียว
3. Safety Guard & Captcha Pause (Human-in-the-loop):
   - มีระบบ Safety Guard คอยสกัดกั้นการลดราคาที่เกินขอบเขต (เช่น ลดเกิน 50%)
   - สแกนหา Captcha/OTP และหยุดรอส่งสัญญาณแจ้งเตือนมนุษย์ให้เข้ามาช่วยปลดล็อกหน้าจอ
4. Token Telemetry & Context Compression:
   - บีบอัด DOM ให้เหลือ Micro-JSON เพื่อประหยัด Token ในการส่งให้ LLM ได้มากกว่า 70-80%
   - บันทึกและวิเคราะห์การใช้ Token (Input/Output/Saved Tokens)

4. การตั้งค่า GOOGLE VERTEX AI สำหรับ OPENWORKER
--------------------------------------------------------------------------------
ไฟล์ Configuration ของ Openworker อยู่ที่:
- Windows: `C:\Users\%USERNAME%\AppData\Roaming\coworker\secrets.json`

การตั้งค่าที่ถูกต้องสำหรับ Vertex AI:
```json
{
  "providers": {
    "vertex": {
      "project": "your-gcp-project-id",
      "location": "global"
    }
  }
}
```
* หมายเหตุสำคัญ: หากตั้งค่าเป็น `us-east5` หรือภูมิภาคเฉพาะ แล้วพบปัญหา ใช้งานไม่ได้ ให้เปลี่ยนกลับเป็น `location: "global"` เสมอ เนื่องจาก global จะทำ Multi-region Routing ไปยังโหนดที่พร้อมให้บริการโดยอัตโนมัติ
